# KeyShot Jewelry Light Engine

A planned jewelry-first lighting assistant for KeyShot. It generates **editable, native
KeyShot light rigs** from presets, adapted to the selected piece and camera, and works
offline.

**Current stage: technical feasibility research.** No product code has been written yet, by
design. Implementation waits until the Phase 1 spike resolves the blocking unknowns.
